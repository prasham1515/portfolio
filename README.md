# Adimire

Personal portfolio built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

This project is configured to deploy under the `/portfolio/` path.

1. Push the project to `https://github.com/prasham1515/portfolio`.
2. Run the deploy script:

```bash
npm run deploy
```

3. In the GitHub repository settings, set GitHub Pages source to the `gh-pages` branch.

The site will be served at:

```text
https://prasham1515.github.io/portfolio/
```
